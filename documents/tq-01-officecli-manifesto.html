功能主义组件库

Full manipulation across 3 formats.

3 Formats

Word (.docx)

  • ✓ 完整 i18n 与 RTL 级联支持
  • ✓ 段落、表格、样式、页眉页脚
  • ✓ 复杂脚本语言排版与双向文本
  • ✓ 内容控制块 (SDT) 与 22 种域控
  • ✓ 批注、脚标、超链接、OLE 对象

Excel (.xlsx)

  • ✓ 150+ 内置函数 (写入即自动求值)
  • ✓ 原生 OOXML 数据透视表引擎
  • ✓ 多键排序、条件格式、切片器
  • ✓ 动态数组函数自动 `_xlfn.` 前缀
  • ✓ 图表生成 (包含 Pareto/箱线图)

PowerPoint (.pptx)

  • ✓ 形态变换 (Morph) 检查与动画
  • ✓ 3D 模型 (.glb) 嵌入与支持
  • ✓ 幻灯片缩放 (Slide Zoom) 效果
  • ✓ 占位符管理 (按 phType 注入)
  • ✓ 音视频、主题、连接符与群组
* All formats support full Create, Read, and Modify capabilities.

The
Engines.

抛弃传统 API。我们内置了专为 AI 视觉与逻辑设计的四大原生引擎。无须依赖外部系统，即可构建 Render → Look → Fix 的自愈闭环。

01. Agent-Friendly 渲染引擎

AI 生成了幻灯片，但它在“盲飞”？OfficeCLI 首次在单体二进制中集成了渲染引擎。将 `.pptx` / `.docx` 渲染为 HTML 或 PNG，甚至 3D `.glb` 和数学公式均可完美呈现。

officecli view deck.pptx screenshot --page 1-N
officecli watch deck.pptx # 本地服务，修改即时刷新

02. 公式与数据透视表引擎

150+ 内置 Excel 函数在写入时自动求值。无需唤起 Excel 软件即可获取计算结果（包含动态数组函数、VLOOKUP、日期函数等）。通过一行命令建立原生的 OOXML 数据透视表缓存，打开即呈现完美图表。

03. 模板合流合并 (Template Merge)

让 Agent 只负责一次昂贵的布局设计，生产代码通过极低成本（零 Token）将 JSON 数据批量注入 `{{key}}` 占位符。跨段落、图表标题、表格单元格完美支持。

officecli merge invoice-template.docx out-001.docx '{"client":"Acme"}'

04. 双向序列化 (Round-trip Dump)

将任意 `.docx` 的任意子树（如一个段落、表格、编号样式）序列化为可重播的批量 JSON 格式。Agent 不再需要解析繁杂的原始 XML，而是阅读结构化规范进行学习与变异生成。

渐进式深度架构 (Three-Layer Architecture)

Start simple, go deep only when needed.

L1
L1

Read / 语义层

高阶视图，获取文本、大纲、标注与统计信息。

view (text, outline, issues, html, screenshot)
L2
L2

DOM / 结构层

基于稳定路径的结构化元素操作，无需理解 XML 命名空间。

get, query, set, add, remove, move, swap
L3
L3

Raw XML / 终极控制层

直接通过 XPath 访问底层数据的通用后备方案。

raw, raw-set, add-part, validate

MCP Server
Built-in.

一键将所有文档操作作为 JSON-RPC 工具暴露给大语言模型。无需 Shell 权限，完美兼容当前主流 AI 编码助手体系。

  • officecli mcp claude # Claude Code
  • officecli mcp cursor # Cursor
  • officecli mcp vscode # VS Code / Copilot
  • officecli mcp lmstudio # LM Studio

确定性 JSON 输出架构

每个操作均支持 --json 参数，并具备统一 Schema 返回、错误纠正建议（自愈闭环）。彻底告别脆弱的正则解析。

{"tag":"shape","path":"/slide[1]","attributes":{"text":"Hello"}}
